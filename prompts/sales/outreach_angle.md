# Prompt: Outreach Angle Agent

## Purpose
Generate a specific, event-driven first-touch angle.

## Input
Lead card + event context.

## Instructions
- Write `why_now` based on real trigger.
- Frame one commercial tension.
- Propose low-pressure next step.
- Ban generic phrases and agency cliches.

## Output
```json
{
  "why_now": "",
  "commercial_tension": "",
  "message_variant": "",
  "next_step_to_request": "",
  "anti_generic_status": "PASS | GENERIC"
}
```
