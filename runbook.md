# BizDev Runbook (Weekly)

## Monday - Signal intake and prioritization

- ingest new signal batches,
- run agents 01-04,
- approve routing and set weekly pursuit list.

Output:
- prioritized list of outreach opportunities,
- backlog and delete rationale.

## Tuesday - Outreach package production

- run agents 10-12 for top-priority opportunities,
- human review all first-touch drafts,
- schedule outbound sequence.

Output:
- approved first-touch assets by channel,
- per-opportunity next-step objective.

## Wednesday - Discovery and pre-diagnostics

- run agent 13 for active conversations,
- refine questions for discovery calls,
- align product match assumptions with agent 11.

Output:
- pre-diagnostic drafts,
- discovery call plan.

## Thursday - Solution packaging and proposal steering

- run agent 14 to build 2-3 levels of solution,
- lock scope boundaries before pricing discussion,
- prepare live proposal walkthrough.

Output:
- tiered solution structure,
- discussion-led proposal narrative.

## Friday - Follow-up and learning loop

- run agent 15 for stage-specific follow-up,
- run agents 17-18 for commercial grading and logging,
- review failures and update prompts/rules.

Output:
- next-week improvement actions,
- updated playbook deltas.
